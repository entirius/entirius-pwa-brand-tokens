# entirius-brand-tokens

The Entirius brand values in one place: `tokens/brand.json` builds into CSS variables, SCSS and a Tailwind preset,
consumed by the CMS, the docs portal and entirius.com. Brand rules: `STYLEGUIDE-GUIDE.md` in `entirius-docs`.

Status: being built (v0.1.0). Installation and usage land with the first release.
